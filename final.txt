1. EXECUTIVE PLATFORM SUMMARY
====================================================================================================
The EV Cyber Academy LFHP Labs platform is a zero-latency, full-featured web-based virtual Linux 
operating system and cyber security simulation environment designed for students of the "Learn the 
Fundamentals of Hacking Program" (LFHP). The platform runs entirely in the modern web browser while 
faithfully simulating an authentic Linux environment (bash scripting, interactive standard input, 
network protocols, DNS servers, target web servers, terminal text editors, and hands-on hacking labs).

3.7. VIRTUAL BASH SCRIPTING ENGINE & INTERACTIVE I/O
----------------------------------------------------------------------------------------------------
- Location: `src/lib/terminal/bash-script-engine.ts`, `src/lib/terminal/executor.ts`, `src/lib/terminal/parser.ts`
- Features:
  * Script Execution Modes:
    - `bash /path/to/script.sh`
    - `sh script.sh`
    - `./script.sh` (with executable permissions)
    - `source script.sh` / `. script.sh`
  * Interactive Standard Input (`read`):
    - `read -p "Enter Target IP: " TARGET_IP` -> Displays prompt, pauses script execution, accepts 
      user input from terminal, sets variable, and resumes.
    - `read -s -p "Password: " PASS` -> Silent password mode masking student input.
    - `read VAR1 VAR2 VAR3` -> Multi-token assignment.
    - `Ctrl+C` interrupt handling to abort active script read prompts.
  * Control Structures:
    - Conditional Blocks: `if [ condition ]; then ... elif [ condition ]; then ... else ... fi`
    - Loop Blocks: `for var in item1 item2 item3; do ... done`
    - While Loops: `while [ condition ]; do ... done`
  * Arithmetic Engine:
    - Arithmetic Expansion: `$(( A + B * C ))` with operator precedence.
    - Arithmetic Command: `(( COUNT = COUNT + 1 ))`.
  * Variable Expansions:
    - Basic: `$VAR`, `${VAR}`
    - Defaults: `${VAR:-default_value}`
    - Special Parameters: `$?` (exit code), `$#` (arg count), `$@` (all args), `$*`, `$0` (script path), `$1`..`$9` (positional args).
  * Command Substitution:
    - Subshell execution: `$(command)` and `` `command` ``.
  * Compound Command Operators:
    - Semicolon sequential execution: `cmd1 ; cmd2 ; cmd3`
    - Logical AND conditional: `cmd1 && cmd2`
    - Logical OR conditional: `cmd1 || cmd2`
